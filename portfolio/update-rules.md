# Portfolio Update Rules

## Update changelog when:
- A bug is fixed
- A helper is added
- A module is refactored
- A small technical improvement is completed

## Update README when:
- A feature or module changes the project story
- A milestone version is completed
- The demo flow changes

## Update CV bullet bank when:
- A new skill is demonstrated
- A new role-targeted positioning becomes available
- A measurable result or stronger evidence is added

## Update LinkedIn draft when:
- A milestone is understandable to non-technical audiences
- There is a clear before-after story
- There are screenshots or demo evidence ready

## Do not update public CV/LinkedIn for:
- Small helper functions
- Minor wording changes
- Internal refactors without a clear story
