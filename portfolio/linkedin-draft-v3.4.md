# LinkedIn Update Draft (V3.4)

I have been polishing a personal portfolio project: **AI Workflow Automation OS**.

It is a personal MVP built with **Google Apps Script, Google Sheets, Telegram Bot API, Gemini API, Gemini Vision, Git, clasp, and AI-assisted development tools**.

The goal was simple: reduce scattered manual tracking across daily habits, screenshot-based records, job applications, and weekly reflection.

The V3.4 version adds a lightweight web command center on top of the existing Telegram and Google Sheets workflow.

Current workflow:

- Telegram captures quick updates and commands.
- Google Apps Script routes inputs and writes structured records to Sheets.
- Gemini Vision supports screenshot-to-structured-data extraction for tested examples.
- Gemini text generation supports weekly AI-assisted review.
- The V3.4 web command center brings Habit, Career, Trading, and AI Audit views into one review surface.

This is not a production SaaS or a plug-and-play template. It is a personal MVP and portfolio case study showing how I approach workflow design, automation, incremental refactoring, documentation, and responsible AI usage.

Before sharing publicly, I also cleaned up the repo for portfolio use:

- moved deployment-specific IDs out of public source,
- documented Script Property configuration,
- added a mock demo checklist,
- and made sure screenshots should use sanitized data only.

The most useful lesson from this project: AI automation becomes more practical when it is connected to structured data, clear review loops, and honest scope boundaries.
