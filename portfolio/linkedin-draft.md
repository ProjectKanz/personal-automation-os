# LinkedIn Update Draft (V2.1)

From working MVP to portfolio-ready automation system.

I just finished V2.1 of my **AI Workflow Automation OS**: a personal MVP/prototype built with **Google Apps Script, Google Sheets, Telegram Bot API, Gemini API, and Gemini Vision**.

The project started as a practical workflow tool for my own operations, then evolved into a cleaner, portfolio-ready system with modular structure, improved configuration safety, and clearer documentation.

What the system currently does:

- Tracks daily activities in a structured Google Sheets workflow
- Converts screenshot-based records into sheet logs using Gemini Vision (tested with MT5 history screenshots)
- Monitors job application progress in one place
- Generates a weekly AI-assisted report from aggregated data

V2.1 highlights:

- **V2.1-A:** modular split (`telegram`, `habit`, `tradingParser`, `weeklyAudit`, `utils`)
- **V2.1-B:** small security and error-handling cleanup (required Script Properties + defensive API response checks)
- **V2.1-C:** portfolio documentation packaging

This is still a **personal MVP/prototype** (not enterprise production software), but it has been a great exercise in workflow automation design, integration, and iterative improvement.
